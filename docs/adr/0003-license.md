# 3. Лицензия: Apache-2.0

Статус: принято

## Контекст

Vinette — self-hosted продукт, который администраторы разворачивают и брендируют под себя; он должен быть пригоден для коммерческого и корпоративного использования.

## Решение

Распространяем под Apache License 2.0.

- Разрешает коммерческое использование, изменение и white-label без обязательства открывать производные работы (в отличие от AGPL/GPL).
- Содержит явную патентную лицензию и защиту от патентных исков, что важно для организаций.
- Совместима с лицензиями всех выбранных зависимостей (MIT, BSD, Apache-2.0, ISC).
- Требует сохранять `LICENSE` и `NOTICE` — это закрепляет атрибуцию «The Vinette Authors» при форках.

Правило для зависимостей: MIT, BSD, Apache-2.0, ISC — допустимы; GPL/AGPL — только с согласия владельца.

## Последствия

- В репозитории лежат неизменённый `LICENSE` и `NOTICE`.
- `package.json` и `Directory.Build.props` содержат лицензионные метаданные (`Apache-2.0`).
- Образы помечаются `org.opencontainers.image.licenses=Apache-2.0`.

# 5. Платформа бэкенда: .NET 11

Статус: принято (владелец, 2026-11-13). В части версии .NET заменяет [ADR-0002](0002-technology-stack.md) (там — .NET 10).

## Контекст

ADR-0002 выбрал ASP.NET Core на .NET 10. Вышел .NET 11; владелец решил перейти на него сразу, пока в проекте нет релизов и пользователей, а кода на платформе ещё немного.

Что известно о .NET 11:

- Это STS-выпуск: по текущему графику Microsoft поддержка 24 месяца (до ноября 2028 года), тогда как .NET 10 — LTS. Следующий LTS — .NET 12 (по плану ноябрь 2027), на него переходим тем же образом.
- Образы Microsoft для .NET 11 построены на Ubuntu 26.04 («resolute»): chiseled-образ называется `aspnet:11.0-resolute-chiseled` (для .NET 10 — `…-noble-chiseled`). Тега `11.0-noble-chiseled` нет.
- Новые анализаторы: `CA2026` требует `JsonElement.Parse(text)` вместо `JsonDocument.Parse(text).RootElement` (иначе документ не освобождается).
- Пакеты платформы (`Microsoft.AspNetCore.OpenApi`, `Microsoft.Extensions.ApiDescription.Server`, `Microsoft.AspNetCore.Mvc.Testing`) для .NET 11 версии 11.0.0. `ApiDescription.Server` 11 запускает генератор OpenAPI на рантайме .NET 11 и поэтому не работает на .NET 10, а образ `dotnet/sdk:11.0` не принимает `global.json` с SDK 10 — переход должен идти разом, по всем частям.

## Решение

1. Целевая платформа — `net11.0`, SDK закреплён в `global.json` (`11.0.100`, `rollForward: latestFeature`).
2. Docker: сборка на `dotnet/sdk:11.0`, поставка на `dotnet/aspnet:11.0-resolute-chiseled` (non-root, без оболочки — как раньше).
3. Пакеты платформы Microsoft — 11.0.x; сторонние пакеты остаются на своих версиях (MailKit 5, HtmlSanitizer 11 и др.).
4. CI берёт SDK из `global.json` (`actions/setup-dotnet` с `global-json-file`), отдельной правки не требует.
5. Остальной стек ADR-0002 не меняется.

## Последствия

- Администраторам «на голом железе» нужен рантайм **ASP.NET Core 11** (`dotnet --list-runtimes`); unit-файл systemd запускает `dotnet Vinette.Api.dll` как прежде.
- Образ собирается на новой базовой ОС: размер и состав chiseled-образа могут отличаться; проверка запуска образа — часть задачи (VIN-136).
- Срок поддержки короче, чем у LTS: к ноябрю 2027 (выход .NET 12 LTS) — запланировать переход, а Dependabot не должен тянуть мажоры платформы в одиночку: их меняет только такое решение.
- Мажорные обновления `Microsoft.AspNetCore.*` / `Microsoft.Extensions.*` и образов `dotnet/*` больше не принимаются без изменения целевой платформы (правила игнорирования в `.github/dependabot.yml`).

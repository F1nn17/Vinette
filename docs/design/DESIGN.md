## 1. Бренд

- Название: **Vinette** (винная линейка проектов). Wordmark: «Vinette», Golos Text 700, letter-spacing −0.02em.
- Значок: скруглённый квадрат цвета акцента; внутри белый контур конверта, клапан которого образует букву V; в точке схождения — белая круглая печать (сургуч и виноградина одновременно).
- Файлы: [vinette.svg](../../frontend/public/icons/vinette.svg) (64×64), [favicon.svg](../../frontend/public/favicon.svg) (16×16, упрощённый, без контура конверта), PNG 32/180/192/512 в `frontend/public/icons/`, [manifest.webmanifest](../../frontend/public/manifest.webmanifest).
- При размере 32 px и меньше линии значка толще (stroke 4.6 в сетке 64). Компонент `Logo` делает это сам.
- Варианты логотипа: на светлом (`#F3F4F6`), на тёмном (`#15171C`, текст белый), на акценте (значок инвертирован: белый квадрат, линии и печать цвета акцента; текст белый).
- **White-label.** Если задан `Branding.Name`, оно заменяет «Vinette» везде. Логотип — из `Branding.LogoPath`; если название своё, а логотипа нет — плитка с первой буквой названия на акцентном фоне. Акцент — `Branding.Accent`; клиент переопределяет `--accent`, `--accent-hover` (темнее на 25%) и `--accent-soft` (акцент с прозрачностью 9%).
- Ограничение: `manifest.webmanifest` статичен и содержит название «Vinette». Подстановка своего названия в манифест — отдельная задача.

## 2. Цветовые токены

Все цвета — только через токены; в компонентах нет цветов вне токенов. Тёмной темы в v1 нет, но токенизация позволяет добавить её переопределением переменных.

### Акцент

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--accent` | `#8E2043` (бордо) | основной цвет, кнопки, фокус |
| `--accent-hover` | `#6B1531` | наведение на primary |
| `--accent-soft` | `#8E204317` (9%) | выбранная строка, активная папка, фон аватаров |
| `--on-accent` | `#FFFFFF` | текст и иконки на акценте |

Пользовательский акцент обязан давать контраст ≥ 4.5:1 с белым текстом (бэкенд проверяет и затемняет при необходимости).

### Текст и поверхности

## 3. Типографика, отступы, формы

- Шрифт: **Golos Text** 400/500/600/700, подключён локально через `@fontsource/golos-text` (без внешних CDN — у приложения строгий CSP; лицензия шрифта OFL-1.1). Моноширинный шрифт в пользовательском UI не используется. Числа — `tabular-nums` (включено глобально).
- Шкала (px):

| Размер | Назначение | Утилита |
| --- | --- | --- |
| 11.5 | заголовки групп: КАПС, 600, letter-spacing .05em; метки | `text-caps` |
| 12–12.5 | метаданные | `text-meta` |
| 13–13.5 | вторичный текст | `text-secondary` |
| 14–14.5 | список, навигация, кнопки | `text-base` |
| 15 | текст письма, line-height 1.65, max 68ch | `text-message` |
| 17–19 | логотип в интерфейсе | `text-logo` |
| 21 | заголовок списка, 700 | `text-heading` |
| 24 | тема письма, 700, lh 1.3 | `text-subject` |
| 26 | заголовок формы входа | `text-form` |
| 40 | крупный заголовок на экране входа | `text-display` |

- Скругления: 6 малые кнопки (`rounded-xs`) · 8 поля и пункты навигации (`rounded-sm`) · 10 основные кнопки и карточки вложений (`rounded-md`) · 12 быстрый ответ (`rounded-lg`) · 14 панели редактора (`rounded-xl`) · 16 карточка входа (`rounded-2xl`) · 999 чипы и метки (`rounded-pill`).
- Отступы кратны 2/4: 4, 6, 8, 10, 12, 14, 16, 20, 24, 28, 32, 40.
- Иконки lucide 18 px, `strokeWidth` 1.8. Кликабельная область ≥ 40 px на десктопе, ≥ 44 px на мобильном.

## 4. Компоненты (примитивы)

Без бизнес-логики, в `frontend/src/shared/ui/`. Каждый покрыт тестом рендера.

| Компонент | Описание |
| --- | --- |
| `Button` | `primary` / `secondary` / `ghost`; размеры sm 36, md 40, lg 44, xl 48; `icon`, `fullWidth`; disabled |
| `IconButton` | обязательный `aria-label`; `pressed` даёт `aria-pressed` (флажок — залитый `#B45309`); 40 px, 44 px на мобильном |
| `Chip` | фильтр, `pressed` → `aria-pressed`; высота 30, выбранный — фон ink, текст белый |
| `LabelTag`, `LabelDot` | метка (11.5/500, padding 2px 8px) и цветная точка 10×10 (радиус 3) |
| `Avatar` | инициалы первых двух слов; `accent` (фон accent-soft) или `neutral` (серый) |
| `Badge` | `success` / `warning`, необязательная иконка |
| `TextField`, `TextArea`, `Select` | всегда с `label`; `hint`, `error` (связаны через `aria-describedby`); фокус — рамка 2 px акцента |
| `Checkbox` | с подписью, кликабельной |
| `ProgressBar` | `role="progressbar"`, обязательный `aria-label`; `accent` или `ink`; полоса 6 px |
| `Logo` | значок + название из брендинга; варианты `light` / `dark` / `accent`; плитка с буквой при своём названии без логотипа |

## 8. Мобильный (< 768 px) и планшет (768–1199 px)

Мобильный — одна колонка:

- шапка: меню (открывает панель папок), заголовок папки 20/700, поиск, кнопка аккаунта;
- ряд чипов-фильтров;
- строки списка: аватар 40 (accent-soft для известных контактов, серый для остальных), отправитель + время, тема, превью + точка непрочитанного;
- плавающая кнопка «Написать» справа внизу: 56 px, радиус 18, тень (`shadow-fab`);
- письмо открывается на весь экран с кнопкой «Назад».

Планшет — две колонки: папки сворачиваются в рейку иконок 64 px, рядом список и область чтения.

## 9. Поведение и состояния

- Клик по строке открывает письмо, оно помечается прочитанным (оптимистично), URL — `/mail/:folder/:messageId`.
- Горячие клавиши: `j`/`k` — следующее/предыдущее, `Enter` — открыть, `r` — ответить, `e` — в архив, `#` — удалить, `/` — поиск, `c` — написать. Подсказки только в диалоге «Горячие клавиши», не на экране.
- Загрузка — скелетоны строк. Ошибки — понятные тосты на языке пользователя. Нет сети — баннер.
- После архивации или удаления — тост с кнопкой «Отменить».
- Настройка плотности списка: обычная / компактная.

## 10. Тексты

- Язык по умолчанию русский, все строки через i18n.
- В пользовательском UI запрещены термины IMAP, SMTP, порт, сервер, DKIM, SPF, TLS, UID, MIME и подобные — им место только в будущей админ-панели.
- Даты в списке: сегодня — «14:32», вчера — «Вчера», на этой неделе — «Вт», раньше — «2 окт.», в прошлые годы — «2 окт. 2025».

## 11. Доступность

- Семантические области: `nav` (папки), `section` с `aria-label` (список), `main` (письмо).
- Видимый фокус: кольцо 2 px цвета акцента (глобальный `:focus-visible`).
- Контраст не ниже WCAG AA.
- Учёт `prefers-reduced-motion` (глобально в `global.css`).
- Все иконочные кнопки с `aria-label` (типы `IconButton` и `ProgressBar` не компилируются без него), все поля с `label`.

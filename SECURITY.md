# Политика безопасности

## Как сообщить об уязвимости

**Не создавайте публичные issues и pull requests** для сообщений об уязвимостях.

Используйте приватную отправку через GitHub Security Advisories: вкладка **Security** → **Report a vulnerability** в репозитории.

Пожалуйста, укажите:

- описание проблемы и её влияние;
- шаги воспроизведения или proof of concept;
- затронутую версию.

Мы подтвердим получение сообщения и сообщим о дальнейших шагах. До выхода исправления просим не раскрывать детали публично.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней минорной версии.

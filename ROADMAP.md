## M1 — Вход и сессии

**Цель:** пользователь входит своими адресом и паролем и получает защищённую сессию.
**Критерий готовности:** вход, `GET /api/v1/me` и выход работают против Dovecot; пароль хранится только зашифрованным на сервере; куки и CSRF защищены; перебор пароля ограничен; интеграционный и e2e-тест входа зелёные.

- [x] **VIN-016 · Интерфейсы Core для входа** (2026-10-20, 59898a3) — модели аккаунта и сессии, `IAuthenticator`, `ISessionStore` в `Vinette.Core` (без MailKit).
  Готово, когда: интерфейсы описаны и покрыты тестом архитектуры (Core без MailKit и ASP.NET); регистрация реализаций в DI — в VIN-017 и VIN-018. Зависит от: VIN-001.
- [x] **VIN-017 · IMAP-аутентификация** (2026-10-20, 6ec3f64) — в `Vinette.Mail` проверка логина через IMAP LOGIN (TLS/STARTTLS по конфигурации) и отправка команды ID с `x-originating-ip` и версией клиента.
  Готово, когда: интеграционный тест: верный пароль — успех, неверный — отказ, недоступный сервер — отдельная ошибка. Зависит от: VIN-016, VIN-013.
- [x] **VIN-018 · Хранилище сессий in-memory** (2026-10-20, a60a593) — непрозрачный идентификатор сессии, пароль шифруется Data Protection, истечение по простою и по максимальному сроку (`Session:*`), фоновая очистка.
  Готово, когда: тесты: сессия истекает по обоим таймерам; пароль не читается без ключа. Зависит от: VIN-016.
- [ ] **VIN-019 · Redis-хранилище сессий (опционально)** — вторая реализация `ISessionStore` для нескольких экземпляров; включается конфигурацией.
  Готово, когда: интеграционный тест на Redis в Testcontainers; без Redis всё работает на in-memory. Зависит от: VIN-018. Нужно согласие владельца на зависимость (StackExchange.Redis, MIT).
- [x] **VIN-020 · Вход и выход** (2026-10-20, e82c3c8) — `POST /api/v1/auth/login`, `POST /api/v1/auth/logout`; cookie HttpOnly, Secure, SameSite=Strict; опция «Оставаться в системе 30 дней».
  Готово, когда: после входа выдаётся cookie, после выхода сессия удалена на сервере. Зависит от: VIN-017, VIN-018, VIN-009.
- [x] **VIN-021 · Текущий пользователь и авторизация API** (2026-10-20, 052ad5f) — `GET /api/v1/me`; политика «по умолчанию доступ только аутентифицированным», 401 в формате ProblemDetails.
  Готово, когда: любой новый endpoint без атрибута закрыт; тест на 401. Зависит от: VIN-020.
- [~] **VIN-022 · Защита от CSRF** — токен для изменяющих запросов (заголовок + cookie), проверка Origin/Referer.
  Готово, когда: POST без токена получает 403; клиент подставляет токен автоматически. Зависит от: VIN-020.
- [ ] **VIN-023 · Rate limiting входа** — ограничение попыток по IP и по аккаунту, нарастающая задержка, ответ 429 с `Retry-After`.
  Готово, когда: тест: после N неверных попыток вход блокируется на заданное время. Зависит от: VIN-020.
- [ ] **VIN-024 · Реальный IP клиента** — настройка доверенных прокси (ForwardedHeaders), передача адреса в IMAP ID и в логи входа; без доверенных прокси заголовки игнорируются.
  Готово, когда: тесты: подделанный `X-Forwarded-For` от недоверенного источника игнорируется. Зависит от: VIN-017.
- [ ] **VIN-025 · Frontend: слой аутентификации** — клиент API (fetch + CSRF), провайдер сессии, защита маршрутов, редирект на `/login`, глобальная обработка 401.
  Готово, когда: незалогиненный пользователь на `/mail/inbox` попадает на `/login`; тесты Vitest. Зависит от: VIN-021, VIN-022.
- [ ] **VIN-026 · Экран входа по дизайну** — две колонки, тёмная панель, карточка, показать/скрыть пароль, чекбокс, фокус-кольца; вариант с OIDC скрыт.
  Готово, когда: совпадает с `login.png` и DESIGN.md §7, клавиатура и скринридер работают. Зависит от: VIN-025, VIN-008.
- [ ] **VIN-027 · Тексты ошибок входа** — понятные сообщения: неверный адрес или пароль, почта временно недоступна, слишком много попыток; ru и en; без технического жаргона.
  Готово, когда: ни одна строка не содержит запрещённых терминов (проверка тестом по списку). Зависит от: VIN-026.
- [ ] **VIN-028 · Тесты входа** — интеграционные (Testcontainers) и e2e-сценарий «вход»: вход, обновление страницы, выход, неверный пароль, блокировка.
  Готово, когда: оба набора зелёные в CI. Зависит от: VIN-013, VIN-014, VIN-026.

## M2 — Пул IMAP-соединений

**Цель:** надёжный и безопасный доступ к IMAP от имени пользователя.
**Критерий готовности:** на пользователя ровно одно рабочее соединение; команды выполняются строго последовательно; обрывы и отзыв пароля обрабатываются; ресурсы освобождаются по простою; есть метрики.

- [ ] **VIN-029 · Абстракция доступа к почте** — интерфейсы в `Vinette.Core` (`IMailGateway`, фабрика сессий) — остальной код работает только через них.
  Готово, когда: в Api и Core нет ссылок на MailKit; архитектурный тест это проверяет. Зависит от: VIN-016.
- [ ] **VIN-030 · Менеджер соединений** — по одному рабочему IMAP-соединению на пользователя, создание по требованию, привязка к сессии.
  Готово, когда: тест: два параллельных запроса одного пользователя используют одно соединение. Зависит от: VIN-029, VIN-017.
- [ ] **VIN-031 · Сериализация команд** — очередь на соединение: `ImapClient` никогда не используется параллельно; отмена через CancellationToken.
  Готово, когда: стресс-тест из 100 параллельных запросов без гонок и взаимоблокировок. Зависит от: VIN-030.
- [ ] **VIN-032 · Переподключение** — повторное подключение с экспоненциальной задержкой; обнаружение отзыва пароля (смена пароля) с завершением сессии.
  Готово, когда: тест: разрыв соединения прозрачен для запроса; неверный пароль после переподключения завершает сессию. Зависит от: VIN-031.
- [ ] **VIN-033 · Таймаут простоя и остановка** — закрытие неактивных соединений, корректное закрытие при остановке приложения.
  Готово, когда: тесты на закрытие по простою и на graceful shutdown. Зависит от: VIN-030.
- [ ] **VIN-034 · Лимиты соединений** — потолок на пользователя и глобальный, ожидание в очереди с таймаутом, понятная ошибка при перегрузке.
  Готово, когда: тест: превышение лимита даёт 503 с `Retry-After`. Зависит от: VIN-030.
- [ ] **VIN-035 · Метрики** — счётчики и гистограммы на `System.Diagnostics.Metrics` (соединения, очередь, длительность команд, ошибки); экспорт (например, Prometheus) — по согласованию.
  Готово, когда: метрики видны при локальном запуске; документированы. Зависит от: VIN-030. Нужно согласие владельца на формат экспорта и зависимость.
- [ ] **VIN-036 · Ошибки IMAP в ProblemDetails** — сопоставление сетевых и протокольных ошибок с кодами API и понятными пользовательскими текстами.
  Готово, когда: таблица соответствий в документации и тесты. Зависит от: VIN-009, VIN-032.
- [ ] **VIN-037 · Тесты устойчивости** — интеграционные тесты: обрыв сети, перезапуск Dovecot, медленные ответы, одновременные пользователи.
  Готово, когда: сценарии зелёные в CI. Зависит от: VIN-013, VIN-031.

## M3 — Папки и список писем

**Цель:** пользователь видит папки и список писем, как на макете «Почта».
**Критерий готовности:** сайдбар и колонка списка соответствуют DESIGN.md §5 на десктопе, планшете и мобильном; список работает на ящике с десятками тысяч писем; состояния загрузки, пусто и ошибки оформлены.

- [ ] **VIN-038 · Идентификатор письма** — тип `(folder, uidValidity, uid)` в Core и в API; обработка смены `uidValidity` (сброс кэша клиента).
  Готово, когда: идентификатор сериализуется стабильно; тест на смену `uidValidity`. Зависит от: VIN-029.
- [ ] **VIN-039 · Папки** — `GET /api/v1/folders`: иерархия, SPECIAL-USE, счётчики непрочитанных (STATUS).
  Готово, когда: интеграционный тест на Dovecot со спецпапками. Зависит от: VIN-031, VIN-038.
- [ ] **VIN-040 · Имена спецпапок** — локализованные названия (Входящие, Отправленные, Черновики, Архив, Спам, Корзина), декодирование modified UTF-7, серверы без SPECIAL-USE (эвристика по именам).
  Готово, когда: тесты для имён Dovecot, Gmail-стиля и кириллических папок. Зависит от: VIN-039.
- [ ] **VIN-041 · Квота** — `GET /api/v1/quota` (GETQUOTAROOT); при отсутствии расширения поле не показывается.
  Готово, когда: тест для обоих случаев. Зависит от: VIN-039.
- [ ] **VIN-042 · Список писем** — `GET /api/v1/folders/{folder}/messages`: отправитель, тема, дата, флаги, признак вложения, метки; сортировка; курсорная пагинация по UID.
  Готово, когда: страницы стабильны при новых письмах; тесты на границы курсора. Зависит от: VIN-039.
- [ ] **VIN-043 · Превью писем** — короткий текстовый фрагмент для списка (расширение PREVIEW либо частичная выборка тела) с лимитом объёма.
  Готово, когда: превью корректно для QP, base64 и разных кодировок. Зависит от: VIN-042, VIN-011.
- [ ] **VIN-044 · Фильтры списка** — «Все», «Непрочитанные», «С флажком» через IMAP SEARCH.
  Готово, когда: фильтры комбинируются с пагинацией. Зависит от: VIN-042.
- [ ] **VIN-045 · Хранилище пользовательских настроек (ADR + реализация)** — где хранить настройки, не помещающиеся в IMAP: цвета меток, подписи, плотность. Варианты: IMAP METADATA, файл в каталоге данных, SQLite. Сначала ADR и согласование.
  Готово, когда: ADR принят владельцем; настройки читаются и пишутся через интерфейс Core; тесты. Зависит от: VIN-018. Требует решения владельца.
- [ ] **VIN-046 · Каркас приложения на фронтенде** — AppShell: три колонки, роутинг `/mail/:folder` и `/mail/:folder/:messageId`, семантические области (nav, section, main), адаптив: десктоп, планшет, мобильный.
  Готово, когда: раскладка переключается на границах 768 и 1200 px. Зависит от: VIN-025.
- [ ] **VIN-047 · Сайдбар** — логотип, переключатель аккаунта (статичный), «Написать», папки со счётчиками, раздел меток, квота.
  Готово, когда: совпадает с `main.png`; активная папка выделена; навигация с клавиатуры. Зависит от: VIN-039, VIN-041, VIN-046.
- [ ] **VIN-048 · Колонка списка** — шапка с заголовком и счётчиком, поле поиска (пока без действия), чипы-фильтры, строка письма (все состояния: не прочитано, флажок, вложение, выбрано).
  Готово, когда: совпадает с макетом в обычной плотности. Зависит от: VIN-042, VIN-044, VIN-046.
- [ ] **VIN-049 · Группы по датам** — СЕГОДНЯ, ВЧЕРА, РАНЕЕ НА НЕДЕЛЕ, месяцы; форматирование дат по DESIGN.md §10 через i18n.
